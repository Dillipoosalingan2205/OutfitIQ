# OutfitIQ: Your AI Fashion Stylist Using Knowledge Graphs👗

OutfitIQ is a smart fashion styling application that helps users create outfit combinations based on their personal information, wardrobe, and occasion.

## Features

- 📸 Selfie capture
- 👤 User profile input
- 👕 Wardrobe upload
- 👖 Clothing categorization
- 👟 Shoes and accessories management
- 📅 Occasion selection
- ✨ Outfit recommendations
- 🎨 Color and styling advice
- 🔄 Start-over functionality

## Technologies Used

- React
- JavaScript / TypeScript
- Tailwind CSS
- Lucide React
- Vite

## How It Works

1. Enter your basic information.
2. Capture or upload your photos.
3. Upload wardrobe items.
4. Select the occasion and time of day.
5. Generate outfit combinations.
6. View styling and color recommendations.

## Project

This project was developed as a fashion styling application prototype.
